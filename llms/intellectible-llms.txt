# Intellectible

> Intellectible is an AI build platform for enterprise service providers - federal and state government contractors (GovCon), professional services firms, and economic development organizations. It turns portals, emails, CRM data, and market signals into structured opportunity, proposal, pricing, and knowledge workflows, and exposes its build environment (workflows, Library files, PostgreSQL databases) through a REST Public API and a Code Execution SDK.

## APIs

- [Intellectible Public API](https://docs.intellectible.com/docs/api-reference/intro): REST API to list and run workflows synchronously and manage Library files; base URL https://app.intellectible.com/api/publicv1; API-key auth via the Authorization header.
